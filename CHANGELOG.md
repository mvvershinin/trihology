# Изменения

## 1.0.2

- Исходные и размеченные снимки сохраняются в `images/` рядом с фактической БД,
  включая импорт файлов и обследования с выключенным автосохранением захвата.
- Относительные ссылки и общий resolver для истории/PDF работают после переноса
  БД вместе со снимками; поддержаны прежние абсолютные пути Linux/Windows.
- История открывает точное измерение кнопкой «Снимки», двойным кликом или Enter
  по строке, в том числе при нескольких обследованиях за один день.
- Метрики и ссылки сохраняются атомарно; ошибки записи изображений не выдаются
  за успешное сохранение. Внешние исходники не изменяются и не удаляются.
- Полная копия `.ptg` содержит БД и связанные снимки с manifest/SHA-256.
  Повреждённые/небезопасные архивы отклоняются до замены; старый `.db` явно
  остаётся копией только базы. Настройки и готовые PDF сохраняются отдельно.

526 тестов, включая переносимость/архивную целостность и GUI-сохранение.
Проверка интерфейса в изолированном профиле включает сохранение обследования,
PDF со снимком и восстановление полного архива в другой каталог.
Работа реального микроскопа
на Windows по-прежнему требует отдельной ручной приёмки.

## 1.0.1

Первый опубликованный выпуск для скачивания: Linux AppImage и Windows ZIP.
Автоматический выпуск по тегу после проверок обеих платформ, контрольные суммы
SHA256SUMS и build-info с версией/ревизией/зависимостями. Английский README,
отдельная инструкция установки и ссылки на русское руководство.

Известное ограничение этой версии: снимки сохранялись внешними/абсолютными
путями, а старый .db backup содержал только БД. Исправление переносимости и
полной копии со снимками ведётся в1.0.2.
Анализ, калибровка, пациенты, серии, история, мультизональные результаты,
PDF и резервное копирование. Исправлены обнаруженные чистой сборкой зависимости
Python, desktop-категория и чтение git-ревизии в контейнере GitHub Actions.

Проверки поставок проходят без физической камеры; ручная приёмка Windows
с USB-микроскопом и чистой Windows без внешних runtime ещё не проведена.

## 1.0.0

Тег подготовки; релиз не опубликован из-за обнаруженной ошибки сборочной среды.

Первый выпуск для скачивания с GitHub: Linux AppImage и Windows ZIP.
Анализ снимков, калибровка, пациенты, серии, история с графиками,
мультизональные результаты, PDF-отчёты и резервное копирование базы.

Автоматическая сборка проверяет интерфейс без камеры, синтетический анализ,
SQLite и PDF. Ручная проверка Windows с USB-микроскопом не выполнена.
