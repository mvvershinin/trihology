# Изменения

## 1.0.0

Первый выпуск для скачивания с GitHub: Linux AppImage и Windows ZIP.
Анализ снимков, калибровка, пациенты, серии, история с графиками,
мультизональные результаты, PDF-отчёты и резервное копирование базы.

Автоматическая сборка проверяет интерфейс без камеры, синтетический анализ,
SQLite и PDF. Ручная проверка Windows с USB-микроскопом не выполнена.
