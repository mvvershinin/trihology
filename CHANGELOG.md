# Изменения

## 1.0.1

Первый опубликованный выпуск для скачивания: Linux AppImage и Windows ZIP.
Анализ, калибровка, пациенты, серии, история, мультизональные результаты,
PDF и резервное копирование. Исправлены обнаруженные чистой сборкой зависимости
Python, desktop-категория и чтение git-ревизии в контейнере GitHub Actions.

Проверки поставок проходят без физической камеры; ручная приёмка Windows
с USB-микроскопом и чистой Windows без внешних runtime ещё не проведена.

## 1.0.0

Тег подготовки; релиз не опубликован из-за обнаруженной ошибки сборочной среды.

Первый выпуск для скачивания с GitHub: Linux AppImage и Windows ZIP.
Анализ снимков, калибровка, пациенты, серии, история с графиками,
мультизональные результаты, PDF-отчёты и резервное копирование базы.

Автоматическая сборка проверяет интерфейс без камеры, синтетический анализ,
SQLite и PDF. Ручная проверка Windows с USB-микроскопом не выполнена.
