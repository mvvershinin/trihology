# Руководство пользователя

## Скачать и запустить

Готовые выпуски: [GitHub Releases](https://github.com/mvvershinin/trihology/releases/latest).
Выберите файл своей системы в разделе Assets. «Source code» — исходники,
а не готовая программа. Если выпуск ещё не опубликован, дождитесь его;
состояние поставки отмечено в [плане](todo/2026-11-07_планы-и-github-релизы.md).

| Система | Файл | Запуск |
|---|---|---|
| Windows 10/11, 64-разрядная | `Phototrichogram-win64.zip` | Полностью распаковать, запустить `phototrichogram.exe` |
| Linux x86_64 | `Phototrichogram-linux-x86_64.AppImage` | Разрешить выполнение файла и запустить |

Windows: Python и SQLite устанавливать не нужно. SmartScreen может предупредить
о неподписанной программе. Проверьте источник и SHA-256; для ожидаемого файла
Windows может предложить «Подробнее» → «Выполнить в любом случае».
Резервный пакет с пусковиком `Фототрихограмма.bat` имеет другую структуру —
см. [сборку под Windows](BUILD_WINDOWS.md).

Linux:

```bash
chmod +x Phototrichogram-linux-x86_64.AppImage
./Phototrichogram-linux-x86_64.AppImage
```

Если системе недоступен FUSE, попробуйте
`./Phototrichogram-linux-x86_64.AppImage --appimage-extract-and-run`.
Если это не поддерживается runtime, извлеките через `--appimage-extract`
и запустите `squashfs-root/AppRun`. Доступ к микроскопу на Linux требует прав
на видеоустройство — см. «Работа с камерой» ниже.

Рядом с файлами релиза есть `SHA256SUMS`: сравните результат `sha256sum` на
Linux или `Get-FileHash -Algorithm SHA256` в PowerShell с нужной строкой.
Сведения о версии и ревизии — в `build-info.json`.

## Данные, обновление и откат

База, настройки, снимки, PDF и журнал лежат **отдельно от программы**:
`~/.phototrichogram` на Linux, `%USERPROFILE%\.phototrichogram` на Windows.
Перед обновлением закройте программу, сделайте резервную копию базы через
«Файл» и сохраните нужные снимки/отчёты. Распакуйте новый выпуск в отдельную
папку; одновременно две версии не запускайте. Для отката сохраните предыдущую
папку программы и резервную копию данных, совместимую с той версией.
Папка программы не заменяет резервную копию данных.

Автоматическая проверка сборки не заменяет проверку микроскопа на вашей
Windows-машине. Фактический статус ручной приёмки указан в описании релиза.

## Рабочий процесс

### 1. Создать пациента

Вкладка **Пациенты**:
- Нажмите **Новый пациент**
- Заполните имя, пол, дату рождения (необязательно), заметки
- Нажмите **Сохранить**
- **Двойной клик** по пациенту в списке — выбрать как активного (имя появится в статусбаре)

### 2. Калибровка (один раз для микроскопа)

Вкладка **Калибровка**:
- Загрузите снимок микрометрической шкалы
- Нажмите **Автокалибровка** или введите масштаб вручную (мкм/пиксель)
- Нажмите **Сохранить калибровку**

Значение 5.9 мкм/пиксель — калибровка одного конкретного микроскопа,
а не универсальная настройка. Для своего микроскопа и увеличения измерьте
масштаб по шкале: ошибка площади поля напрямую меняет плотность.

### 3. Загрузить снимки по зонам

Вкладка **Захват**:
- 4 карточки зон: **F** (лобная), **P** (теменная), **T** (височная), **O** (затылочная — контроль)
- Для каждой зоны: нажмите **Загрузить** (из файла) или **Снимок** (с камеры)
- Загруженный снимок отобразится в миниатюре карточки
- Клик по миниатюре — показать в большом превью слева
- Зона **O (затылочная)** — контрольная, используется для сравнения

### 4. Запустить анализ

На вкладке **Захват**:
- Загрузите хотя бы 1 зону (лучше все 4)
- Нажмите **Анализировать загруженные**
- Дождитесь завершения (прогрессбар)
- Автоматический переход на вкладку **Результаты**

Если выбран активный пациент — результаты автоматически сохраняются в базу данных.

### 5. Просмотр результатов

Вкладка **Результаты**:
- **Карточки зон** — плотность, % Vellus, T/V ratio, разница с контролем
- **Цветовые индикаторы**: зелёный (норма), жёлтый (пограничное), красный (за пределами нормы)
- **Графики**: плотность по зонам, типы волос (%), гистограмма толщин
- **Клик по карточке** — подробная статистика зоны

### 6. Анализ одиночного снимка

Вкладка **Анализ**:
- Загрузите изображение
- Нажмите **Анализировать**
- Результат: таблица метрик + гистограмма толщин
- Кнопка **Показать разметку** — переключение на аннотированный снимок (контуры + подписи)

### 7. История и динамика

Вкладка **История** (нужен выбранный пациент):
- Таблица всех измерений пациента (дата, зона, плотность, T/V)
- Графики динамики: плотность и T/V ratio по датам для каждой зоны

## Зоны скальпа

| Код | Зона | Назначение |
|-----|------|-----------|
| F | Лобная | Линия роста волос на лбу |
| P | Теменная | Верх головы (макушка) |
| T | Височная | Боковые области |
| O | Затылочная | Контрольная зона (наименее подвержена выпадению) |

## Метрики

| Метрика | Норма | Что означает |
|---------|-------|-------------|
| Плотность | 150-300 волос/см² | Количество волос на единицу площади |
| Vellus % | <20% | Доля тонких пушковых волос (<30 мкм) |
| T/V ratio | >4.0 | Соотношение терминальных к пушковым |
| Средняя толщина | 40-80 мкм | Средний диаметр волос |

## Работа с камерой

1. Подключите USB-микроскоп
2. На вкладке **Захват** нажмите **Обновить** (список устройств)
3. Выберите камеру в выпадающем списке
4. Нажмите **Подключить**
5. Живое превью появится слева
6. Нажмите **Снимок** на карточке нужной зоны

На Windows настройка udev не нужна. На Linux для работы без sudo нужны
udev-правила (скрипт доступен в исходном репозитории):
```bash
sudo bash install-udev.sh
```
Если ваш пользователь ещё не в группе `video`, скрипт подскажет команду
`sudo usermod -aG video $USER` (нужен повторный вход в систему, чтобы
членство в группе применилось). Временное решение без установки правила,
до перезагрузки:
```bash
sudo chmod a+rw /dev/video*
```

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| Ctrl+O | Открыть изображение |
| Ctrl+S | Сохранить результат |
| Ctrl+Q | Выход |


## Снимки рядом с базой и полная резервная копия (с 1.0.2)

Исходники и разметка сохраняются в `images/` рядом с **фактическим файлом БД**,
включая выбор другой базы через конфигурацию. Место программы и рабочая папка
не влияют на эти пути. Импорт копирует файл в хранилище; исходный файл не меняется.
В БД новые ссылки относительные, поэтому БД и `images/` можно переносить вместе
между Linux и Windows. Старые абсолютные ссылки поддерживаются, пока исходный
файл доступен или его точная копия перенесена в соседнюю `images/`.

В «История» выберите конкретную строку обследования и нажмите **«Снимки»**.
Также работают двойной клик и Enter по строке. Это позволяет открыть нужное
измерение, даже если несколько обследований за день совпали на графике.
Запись без когда-либо сохранённого снимка не означает, что программа может
воссоздать его; отсутствующие изображения нельзя подменять похожими.

«Файл → Резервная копия базы…» по умолчанию создаёт **`.ptg` — БД и все
привязанные исходники/аннотации**. Восстановление проверяет архив и контрольные
суммы до замены данных. Настройки `config.json` и экспортированные PDF не входят
в этот архив: сохраняйте их отдельно. Если снимок, указанный в БД, отсутствует,
полная копия завершится ошибкой, а не выдаст неполную копию за успешную.

Старый формат `.db` остаётся совместимым, но содержит **только базу**. Перед
выбором этого формата показывается предупреждение; для переноса изображений
нужна отдельная папка `images/` либо новая полная копия `.ptg`.
