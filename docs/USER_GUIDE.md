# Руководство пользователя

## Рабочий процесс

### 1. Создать пациента

Вкладка **Пациенты**:
- Нажмите **Новый пациент**
- Заполните имя, пол, дату рождения (необязательно), заметки
- Нажмите **Сохранить**
- **Двойной клик** по пациенту в списке — выбрать как активного (имя появится в статусбаре)

### 2. Калибровка (один раз для микроскопа)

Вкладка **Калибровка**:
- Загрузите снимок микрометрической шкалы
- Нажмите **Автокалибровка** или введите масштаб вручную (мкм/пиксель)
- Нажмите **Сохранить калибровку**

Дефолтное значение — 5.9 мкм/пиксель (для USB-микроскопа 640x480 @ 200x).

### 3. Загрузить снимки по зонам

Вкладка **Захват**:
- 4 карточки зон: **F** (лобная), **P** (теменная), **T** (височная), **O** (затылочная — контроль)
- Для каждой зоны: нажмите **Загрузить** (из файла) или **Снимок** (с камеры)
- Загруженный снимок отобразится в миниатюре карточки
- Клик по миниатюре — показать в большом превью слева
- Зона **O (затылочная)** — контрольная, используется для сравнения

### 4. Запустить анализ

На вкладке **Захват**:
- Загрузите хотя бы 1 зону (лучше все 4)
- Нажмите **Анализировать загруженные**
- Дождитесь завершения (прогрессбар)
- Автоматический переход на вкладку **Результаты**

Если выбран активный пациент — результаты автоматически сохраняются в базу данных.

### 5. Просмотр результатов

Вкладка **Результаты**:
- **Карточки зон** — плотность, % Vellus, T/V ratio, разница с контролем
- **Цветовые индикаторы**: зелёный (норма), жёлтый (пограничное), красный (за пределами нормы)
- **Графики**: плотность по зонам, типы волос (%), гистограмма толщин
- **Клик по карточке** — подробная статистика зоны

### 6. Анализ одиночного снимка

Вкладка **Анализ**:
- Загрузите изображение
- Нажмите **Анализировать**
- Результат: таблица метрик + гистограмма толщин
- Кнопка **Показать разметку** — переключение на аннотированный снимок (контуры + подписи)

### 7. История и динамика

Вкладка **История** (нужен выбранный пациент):
- Таблица всех измерений пациента (дата, зона, плотность, T/V)
- Графики динамики: плотность и T/V ratio по датам для каждой зоны

## Зоны скальпа

| Код | Зона | Назначение |
|-----|------|-----------|
| F | Лобная | Линия роста волос на лбу |
| P | Теменная | Верх головы (макушка) |
| T | Височная | Боковые области |
| O | Затылочная | Контрольная зона (наименее подвержена выпадению) |

## Метрики

| Метрика | Норма | Что означает |
|---------|-------|-------------|
| Плотность | 150-300 волос/см² | Количество волос на единицу площади |
| Vellus % | <20% | Доля тонких пушковых волос (<30 мкм) |
| T/V ratio | >4.0 | Соотношение терминальных к пушковым |
| Средняя толщина | 40-80 мкм | Средний диаметр волос |

## Работа с камерой

1. Подключите USB-микроскоп
2. На вкладке **Захват** нажмите **Обновить** (список устройств)
3. Выберите камеру в выпадающем списке
4. Нажмите **Подключить**
5. Живое превью появится слева
6. Нажмите **Снимок** на карточке нужной зоны

Для работы без sudo нужны udev-правила:
```bash
sudo bash install-udev.sh
```
Если ваш пользователь ещё не в группе `video`, скрипт подскажет команду
`sudo usermod -aG video $USER` (нужен повторный вход в систему, чтобы
членство в группе применилось). Временное решение без установки правила,
до перезагрузки:
```bash
sudo chmod a+rw /dev/video*
```

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| Ctrl+O | Открыть изображение |
| Ctrl+S | Сохранить результат |
| Ctrl+Q | Выход |
