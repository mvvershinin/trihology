# Roadmap — Phototrichogram

## v1.0 MVP — Захват + Анализ + Калибровка

### Готово
- [x] Структура проекта, package scaffolding
- [x] `utils/config.py` — AnalysisConfig, CameraConfig, AppConfig, load/save JSON
- [x] `utils/image_utils.py` — BGR/PIL/PhotoImage конвертация, resize, load/save
- [x] `core/segmentation.py` — CLAHE + intermodes/Otsu + морфология → маска
- [x] `core/measurement.py` — MinFeret толщина, MinAreaRect, HairMeasurement
- [x] `core/classification.py` — Terminal/Vellus/Intermediate
- [x] `core/calibration.py` — автокалибровка по шкале микрометра
- [x] `core/camera.py` — V4L2 камера, Protocol, list_devices
- [x] `core/stats.py` — плотность, T/V ratio, статистика, сравнение зон
- [x] `core/analyzer.py` — оркестратор пайплайна с аннотацией
- [x] `gui/widgets.py` — StatusBar, ImageCanvas (zoom/pan), ToolTip, ScrollableFrame
- [x] `gui/app.py` — главное окно, меню, настройки, медицинский дисклеймер
- [x] `gui/capture_tab.py` — live-превью, снимки, миниатюры
- [x] `gui/analysis_tab.py` — анализ + результаты + гистограмма matplotlib
- [x] `gui/calibration_tab.py` — авто/ручная калибровка
- [x] `main.py` — точка входа с проверкой зависимостей
- [x] `requirements.txt`, `requirements-dev.txt`
- [x] Code review + architecture validation + bugfixes
