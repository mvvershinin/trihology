# План развития v1.2 — v1.3

## v1.2 — PDF-отчёты + Бэкап БД

### Phase 1: PDF-отчёты
**Agent**: gui-expert + cv-expert
**Сложность**: moderate
**Files**: `reports/pdf_report.py`, `gui/multizone_tab.py`

- Генерация PDF через fpdf2:
  - Шапка: пациент, дата, калибровка
  - Аннотированные снимки по зонам
  - Таблица метрик (плотность, T/V, vellus%, толщина)
  - Сравнение с контролем (%)
  - Графики matplotlib → PNG → вставка в PDF
- Кнопка "Экспорт отчёта" на вкладке Результаты → сохранить PDF
- **Без диагнозов и рекомендаций** — только метрики и графики

### Phase 2: Бэкап/восстановление БД
**Agent**: db-expert + gui-expert
**Сложность**: simple

- Меню: Файл → Бэкап БД / Восстановить БД (с диалогом выбора файла)
- Документация: ручной бэкап — скопировать `~/.phototrichogram/phototrichogram.db`

## v1.3 — Дерматоскопические признаки (фиброз, себорея)

### Phase 1: CV-детекция паттернов
**Agent**: cv-expert (Opus)
**Сложность**: complex
**Files**: `core/dermatoscopy.py`, `utils/config.py`

Детекция дерматоскопических паттернов на снимках скальпа:
- **Перифолликулярный фиброз** — белые ореолы вокруг фолликулов (цветовое пространство + морфология)
- **Себорея** — жёлтые чешуйки/корки (сегментация в HSV)
- **Yellow dots** — пустые фолликулы (детекция круглых жёлтых объектов)
- **Black dots** — обломанные волосы (мелкие тёмные точки)

Результат: наличие/отсутствие каждого признака + процент площади.
Все пороги — настраиваемые через AnalysisConfig.

### Phase 2: Интеграция в GUI
**Agent**: gui-expert
**Сложность**: moderate
**Files**: `gui/multizone_tab.py`, `gui/analysis_tab.py`, `data/models.py`, `data/database.py`

- Дополнительные метрики в карточках зон (фиброз %, себорея %)
- Столбцы в таблице истории
- Сохранение в БД (миграция схемы)
- Включение в PDF-отчёт

### Phase 3: Тестовые данные
**Agent**: cv-expert
**Сложность**: moderate

- Нужны реальные снимки с фиброзом и себореей для калибровки алгоритмов
- Синтетические тестовые изображения для pytest

## Принципы

- **Только метрики** — без диагнозов, названий болезней, рекомендаций
- Фиброз: "12% площади" — а не "рубцовая алопеция"
- Себорея: "жёлтые чешуйки: 8%" — а не "себорейный дерматит"
