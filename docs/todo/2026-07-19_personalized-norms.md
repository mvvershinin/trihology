# План v1.5: персонализированные нормы (пол + возраст + этнос)

**Дата**: 2026-07-19
**Основание**: требование пользователя — нормы по современной научной
литературе с учётом расовых особенностей, пола и возраста; параметры завести
в карточку пациента.

## Научная основа (источники в docs/METHODOLOGY.md, новый раздел «Референсные нормы»)

Плотность (волос/см², здоровые взрослые):
- Европеоиды ~180–250 (лоб 230, макушка 226, затылок 214)
- Латиноамериканцы ~170–180
- Африканцы ~148–160
- Восточная Азия ~140–150 (меньше фолликулов, но толще волос)

Толщина терминального волоса (мкм): Азия 80–120 · Европа 60–90 · Африка 55–90.
Vellus норма: затылок ~6–7%, лоб ~10–11% (не «<20%» как было).
Возраст: значимое снижение плотности после ~35 лет.
Пол: плотность близка; важнее паттерн (сравнение зон с затылком).

Источники (PubMed/PMC): оценка плотности по этносам (PMC6219221),
тайская популяция (PMC7035527), индийские мужчины (PMC11753574),
норма у здоровых женщин (PMC3157785), дети (PMC6830029).
ВСЕ значения — справочные, НЕ диагноз.

## Task: Персонализированные нормы

### Phase 1 — Фундамент норм (ядро)
**Agent**: cv-expert
**Files**: `core/norms.py` (новый), `tests/test_norms.py` (новый)
- Enum `Ethnicity` (европеоид / восточноазиат / африканец / латиноамериканец /
  южноазиат / не указан) и `Sex` (или переиспользовать строку пола из моделей —
  но core НЕ зависит от data, поэтому свои типы/литералы)
- Датакласс `NormRange(low, high, borderline_low)` и `PatientNorms` (плотность,
  vellus%, T/V, толщина) — все со ссылкой на источник
- Таблицы референсов из литературы (модульные константы, документированы)
- `select_norms(sex, age_years, ethnicity) -> PatientNorms` — выбор с
  разумными fallback: этнос не указан → усреднённая/широкая норма (текущая
  150–300 как «общая»); возраст None → взрослый; коррекция плотности по
  возрастным полосам (после ~35 снижать нижнюю границу)
- Чистая функция, без побочек, без зависимостей от data/gui
- Тесты: каждая ветка этноса, возрастная коррекция, fallback'и
