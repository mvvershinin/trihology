## Решение

Managed media принадлежат фактическому db_path.parent/images, независимо от cwd,
места exe, ОС и старого images_dir. В БД относительные POSIX-пути, единый
ImageStore resolver для history/preview/PDF/multizone. Legacy абсолютные POSIX
и Windows пути поддержать. Импорт и аннотации копировать с проверкой,
без перезаписи исходников/коллизий; ошибки сохранения не выдавать за успех.

Полный backup — совместимый архив SQLite online snapshot + referenced images
+ manifest/checksums. Старый .db формат остаётся database-only и явно так
подписан. Restore сначала проверяет весь архив, затем публикует данные;
ошибка не должна уничтожить текущую БД или изображения.

## Этапы и владельцы файлов

1. **Data/storage — db-expert:** utils/image_storage.py, data/database.py,
   при необходимости models; тесты storage/backup. API ImageStore(db_path),
   root/images_dir, import_file(source)->relative str, resolve(ref)->Path|None;
   Database.image_store; backup/restore dispatch archive и legacy .db.
2. **GUI/readers — gui-expert:** gui/, reports/ и utils/image_utils.py;
   импорт/capture/annotation/save failure, readers через resolver,
   корректный fallback, GUI полного backup/restore и meaningful tests.
3. **Recovery — coordinator:** только рабочая БД владельца после backup;
   безопасная копия и относительная нормализация80 известных файлов.
   Для28 старых измерений искать surviving files/log provenance;
   привязка только по однозначному сочетанию provenance/метрик/сессии/зоны.
   Одного timestamp+zone недостаточно; сомнительное оставить непривязанным,
   локальный candidate manifest без ФИО. Исходные файлы не удалять.
4. **Проверки:** targeted переносимость между Linux/Windows, внешний импорт,
   одинаковые basenames разного содержимого, ошибки записи, архивный restore,
   legacy paths, полный pytest/ruff/mypy/import-linter; один architecture и
   code-critic проход, исправление существенных находок без цикла.
5. **Поставка:** CHANGELOG/docs/общий план актуализировать; commit/push и
   patch v1.0.2 если свободен, без force. Дождаться Linux/Windows assets,
   скачать и сверить SHA-256. Реальный Windows микроскоп не считать принятым.
