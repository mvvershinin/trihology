## Осталось

### Клинически ценное

✅ **PDF-отчёты** (готово 2026-07-19) — распечатка для пациента: метрики, снимки,
   сравнение зон, персональные нормы, кириллица из пакета. Экспорт привязан к
   показанной сессии (провенанс), дата исследования ≠ дата печати, устойчив к
   битым снимкам. Настраиваемая папка отчётов. Ревью пройдено.
⬜ **Прогон режима «от корней» на реальных снимках** — сравнить плотность all vs
   rooted по зонам, решить дефолт (сейчас «все»).
⬜ **Склейка фрагментов волоса** — волос из фокуса рвётся на 2–4 контура, каждый
   считается отдельным → завышение плотности. Склейка коллинеарных фрагментов
   (направление + малый зазор). Сложное, ближе к watershed (v2.0), но отдельно.

### Техдолг (быстро и безопасно)

⬜ **Свести нормы `core/diagnosis.py` и `core/stats._assess_zone` к `core/norms`** —
   дублируют старые пороги (плотность 150, vellus <20%), расходятся с ядром.
   Сейчас только в тестах, но ДО PDF-отчётов привести в порядок.
⬜ **Дубль раскраски статусов в `gui/multizone_tab._assess_status`** — третья
   копия логики рядом с diagnosis/stats. Единый классификатор в core, GUI зовёт.
⬜ **N+1 запрос** в `history_tab._load_series` — get_session в цикле,
   переиспользовать session_id→date из refresh.
⬜ **Неиспользуемый `self._lock` (RLock)** в Database — убрать или реально
   использовать (ложное впечатление синхронизации).
⬜ Докстринг `hair_count`: при серии это среднее на снимок, не «общее».
⬜ Крайний случай T/V из сумм ≥99.9 при vellus>0 покажет «нет пушковых» (редко).
⬜ Окно снимков рисует только 5 миниатюр, БД число не ограничивает.
⬜ Аннотируется каждый снимок серии, а хранится только последний — гонять
   `analyze()` для всех, кроме последнего (экономия CPU).

### Методология и документация

⬜ **Актуализировать METHODOLOGY §4** — описывает Intermodes + fill_holes вместо
   реального black-hat пайплайна (стоит только пометка об устаревании).
⬜ Транзитные волосы: методологический вопрос дефолта (частично решено режимом
   «от корней»).
⬜ Косметика: подпись полосы плотности — «типичная верхняя граница», не потолок.
